01

先認識你的 Soup

BeautifulSoup 不負責下載網頁，它負責把已取得的 HTML 轉成容易搜尋、遍歷和修改的 Python 物件。先安裝套件，再把 HTML 餵給它。

pip install beautifulsoup4 requests from bs4 import BeautifulSoup html = "<h1>Hello, Soup!</h1>" soup = BeautifulSoup(html, "html.parser") print(soup.h1.get_text()) # Hello, Soup!
小提醒： `html.parser` 是 Python 內建解析器，適合多數練習；遇到不完整或非常複雜的 HTML，可以改用 `lxml`。

02

像查地圖一樣選取元素

知道元素的標籤名稱，就用 `find`；知道 CSS class 或 id，就用 `select_one` 和 `select`。`find` 找一個，`find_all` 找一組。

# 第一個 h2 title = soup.find("h2") # 找 id="price" 的元素 price = soup.select_one("#price") # 找所有 class="product" 的卡片 products = soup.select(".product") for product in products: print(product.get_text(strip=True))
需求方法回傳
找第一個標籤soup.find("a")Tag 或 None
找所有標籤soup.find_all("a")ResultSet
使用 CSS 選擇器soup.select(".card a")list
03

把節點變成乾淨資料

找到標籤只是中途站。接下來要取出文字、連結、圖片網址與自訂屬性，並處理元素不存在的情況。

for card in soup.select("article.product"): name = card.select_one("h2").get_text(strip=True) link = card.select_one("a").get("href") image = card.select_one("img").get("src", None) item = {"name": name, "link": link, "image": image} print(item)
使用 get_text(strip=True) 清理空白
使用 get("href") 讀取屬性
使用 get(key, default) 防止 KeyError
對 select_one 結果做 None 檢查
04

進階：讓流程更可靠

真實網站常有分頁、表格、巢狀結構與不固定欄位。把解析邏輯拆小，資料清理和錯誤處理就會容易很多。

分頁與表格

for row in soup.select("table tbody tr"): cells = [cell.get_text(strip=True) for cell in row.select("td")] if len(cells) >= 3: records.append({"name": cells[0], "price": cells[1], "stock": cells[2]}) # 找下一頁連結 next_url = soup.select_one("a[rel='next']") if next_url: url = urljoin(url, next_url["href"])

與 requests 串起來

尊重網站：檢查 robots.txt、設定合理的請求間隔、保留 User-Agent，並確認資料使用符合網站條款。
05

實戰：抓取商品清單

把前面的技巧組合起來：下載頁面、檢查狀態、解析每張商品卡，再輸出成容易儲存的資料結構。

import requests from bs4 import BeautifulSoup def parse_products(url): response = requests.get(url, timeout=10, headers={"User-Agent": "Mozilla/5.0"}) response.raise_for_status() soup = BeautifulSoup(response.text, "html.parser") results = [] for card in soup.select(".product-card"): results.append({ "name": card.select_one(".name").get_text(strip=True), "price": card.select_one(".price").get_text(strip=True), }) return results
